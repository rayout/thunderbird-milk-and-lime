# Milk & Lime 0.1.0

A standalone light Thunderbird theme with soft neutral surfaces, graphite text and green accents.
No access to mail, contacts or external services. No scripts or custom CSS installation required.

Install `milk-lime-theme-0.1.0.xpi` using Add-ons and Themes → gear menu → Install Add-on From File,
then enable Milk & Lime. Switch to another theme or remove it to revert the palette.

This theme does not change fonts, card layout, tags, avatars or Conversations.
For those features, see the separate extension and optional advanced style pack.
Compatibility is deliberately limited to Thunderbird 157.x; other versions are not claimed.
The theme ID is retained to support upgrades from local builds.
